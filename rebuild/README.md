# День ежа — новая HTML-игра

Чистая реализация, созданная заново только на основе презентации `день ежа.pptx`.

- 9 экспортированных экранов PowerPoint;
- 7 последовательных испытаний;
- задания на `was / were`, вопросы, отрицания и исправление ошибок;
- подсказки, листочки, промежуточные результаты;
- порог прохождения 60%;
- полноэкранный режим и простые звуковые сигналы.

Для запуска откройте `index.html` в браузере.
