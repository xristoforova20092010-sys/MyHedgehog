# День ежа

Браузерная обучающая игра по английскому языку на тему **Past Simple: was / were**.

Игрок помогает ёжику пройти семь лесных испытаний и вернуться домой. За правильные ответы начисляются листочки, за завершённые этапы — жёлуди.

## Возможности

- семь последовательных испытаний;
- проверка правильных и неправильных ответов;
- подсказки с уменьшением награды;
- рисованные игровые кнопки;
- шесть фоновых мелодий;
- звуковые эффекты, раздельная громкость и отключение звука;
- полноэкранный режим;
- поддержка мыши и сенсорного экрана.

Игра не требует установки и открывается как обычная веб-страница. Публикация выполняется автоматически через GitHub Pages.
